# ── Handwriting recognition (both engines optional at runtime) ────────────
# EasyOCR does double duty: it is the Fast reader (CRAFT detection plus
# recognition in one pass), and its CRAFT detector also supplies the line
# geometry that Accurate mode crops for TrOCR. Measured on a handwritten test
# page, Tesseract's layout analysis found 4 of 6 lines and CRAFT found all 6, so
# Accurate is noticeably better with EasyOCR installed than without — it still
# runs either way, falling back to Tesseract geometry.
# torchvision must be installed FIRST, pinned, and with --no-deps: a plain
# `pip install easyocr` resolves its own torch and will replace the working
# torch 2.11.0+cpu that Whisper depends on. 0.26 is the release paired with
# torch 2.11 in the upstream support matrix.
#   pip install --no-deps "torchvision==0.26.*"
#   pip install --no-deps easyocr
#   pip install shapely pyclipper "python-bidi<0.6"
